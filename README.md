# The Music Files

Διαδραστική εκπαιδευτική σειρά serious games για τον γραμματισμό στα μέσα, την οπτική ανάλυση, την ανάλυση δικτύων και την κριτική ερμηνεία δεδομένων.

Η πρώτη σεζόν περιλαμβάνει έξι υποθέσεις που εξερευνούν την οπτική ομοιότητα, τα δίκτυα συνεργασιών, τις κοινότητες, τα μεταδεδομένα, τη χρονολογική σειρά και τα μοντέλα πρόβλεψης.

**Κεντρική αρχή:** ένα μοτίβο αποτελεί ένδειξη — όχι από μόνο του εξήγηση.
